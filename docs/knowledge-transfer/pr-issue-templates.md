## 📋 概要

本文書は、**AI駆動開発プロジェクトで使用する実践的なPR・Issueテンプレート**を提供します。

**背景**:
- 約30,000字の大規模文書作成プロジェクトで実証

## 📝 PRテンプレート

### テンプレート1: レビュー範囲明記型（並行PR用）

```markdown
## 📋 レビュー対象範囲の明確化

**新規追加部分**: [セクション名] のみ（約[文字数]字）

**既存部分**（前のPRでレビュー済み、レビュー対象外）:
- [セクション名]（約[文字数]字、PR #[番号]でレビュー済み）
- [セクション名]（約[文字数]字、PR #[番号]でレビュー済み）

**レビュー依頼**:
- [新規セクション] の内容を重点的にレビューしてください
- [既存セクション] との接続は軽く確認してください（オプション）

---

## 🎯 変更内容

[具体的な変更内容]

---

## ✅ チェックリスト

- [ ] 新規追加部分を明記した
- [ ] 既存部分（レビュー済み）を明示した
- [ ] レビュー範囲を明確化した
- [ ] 前のPR番号を記載した
```

**適用場面**:
- 1つのファイルに対する並行PR
- 大規模ファイルの段階的開発

**効果**:
- トークン消費の最適化（71%削減の実績）
- レビューの一貫性

**関連**: [並行PR戦略](parallel-pr-strategy.md)

## 📋 Issueテンプレート

### テンプレート1: 失敗事例Issue

```markdown
## 📋 概要

**発生日時**: YYYY-MM-DD  
**フェーズ**: Step X  
**重要度**: [高/中/低]  
**関連Issue**: #Y, #Z

---

## ❌ 失敗事例 #N: [タイトル]

### 何が起きたか

#### 実際の行動
- [具体的な行動]

#### 問題点
- [何が問題だったか]

---

### 根本原因分析

#### 原因1: [原因名]
- [詳細]

#### 原因2: [原因名]
- [詳細]

---

### 影響

#### 直接的影響
- [即座の影響]

#### 潜在的リスク
- [将来の影響]

---

## ✅ 再発防止策

### 1. [対策名]
- [具体的な対策]
- [チェック項目]

### 2. [対策名]
- [実践方法]

---

## 🔗 関連リソース

### GitHub Issue
- [関連Issue]

### ファイル
- [ルールファイル等]

---

## 🎯 ステータス

- [x] 失敗の認識完了
- [x] 根本原因分析完了
- [x] 再発防止策の確立完了
- [ ] ルールファイル更新予定

**結論**: 解決済み・再発防止策確立
```

**適用場面**:
- 失敗・エラー発見時
- 根本原因分析が必要な問題

**関連**: [失敗事例と再発防止](failure-recovery-best-practices.md)
